# Нейропомощник

Простое веб-приложение для повседневных задач с использованием Google Gemini API.

## Функциональность

- 🤖 Интеграция с Google Gemini API
- 💬 Интерфейс чата с историей сообщений
- ⚙️ Настраиваемый системный промпт
- 📱 Адаптивный дизайн для мобильных устройств
- 💾 Сохранение API ключа и настроек в localStorage
- 🎨 Современный UI с градиентным дизайном

## Установка и запуск

### 1. Клонирование и установка зависимостей

```bash
git clone <repository-url>
cd ai-helper
npm install
```

### 2. Получение API ключа

1. Перейдите в [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Создайте новый API ключ для Gemini API
3. Скопируйте ключ

### 3. Запуск в режиме разработки

```bash
npm run dev
```

Приложение откроется в браузере по адресу `http://localhost:3000`

При первом запуске система попросит вас ввести API ключ.

### 4. Сборка проекта

```bash
npm run build
```

## Использование

1. **Настройка системного промпта**: В поле "Системный промпт" можно задать роль и поведение ассистента
2. **Отправка запросов**: Введите ваш вопрос в текстовое поле и нажмите "Отправить"
3. **Просмотр ответов**: Ответы отображаются в области чата с историей диалога

## Особенности

- **Фронтенд решение**: Все запросы выполняются напрямую с клиента
- **Безопасность**: API ключ хранится в localStorage браузера
- **Производительность**: Используется Gemini 1.5 Flash для быстрых ответов
- **UX**: Индикаторы загрузки, обработка ошибок, адаптивный дизайн

## Сброс API ключа

Если вам нужно изменить API ключ, выполните в консоли браузера:

```javascript
localStorage.removeItem('geminiApiKey');
location.reload();
```
